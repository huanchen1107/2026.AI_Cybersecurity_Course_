# AIIS_L1 — BUILD：Build Your First AI Weather Security Center

> **Status: CANONICAL ALIGNMENT — 2026-09-07**
>
> This file replaces the earlier Lesson 1 allocation that treated L1 as a broad AI Security Engineer Toolbox. Detailed Antigravity + GitHub workflow now belongs to **AIIS_L2**; Python/API internals belong to **AIIS_L3**; formal scanner/remediation workflow belongs to **AIIS_L4**.

## Mission

學生第一次體驗：

```text
Structured Build Prompt
        ↓
AI / Antigravity
        ↓
Working Weather Security Center
        ↓
WORKING ✓
        ↓
SECURE ?
```

L1 的目的不是一次教完所有工具，而是先建立真實、可持續使用的共同 Lab，並完成從「AI 能做出軟體」到「能跑不代表安全」的認知轉折。

## Core Learning Outcomes

1. 看見 `Prompt → Working Software` 的完整體驗。
2. 使用真實 CWA weather data 建立 AI Weather Security Center。
3. 認識 Asset → Threat → Vulnerability → CIA → Risk。
4. 理解 `WORKING ≠ SECURE`。
5. AI 從 Builder 轉換為 Security Analyst。
6. 學會要求 evidence，而不是直接相信 AI 結論。
7. 建立 `AI BUILDS. HUMAN VERIFIES.` 的課程習慣。

## Canonical Story

```text
BUILD FIRST
Prompt → Antigravity → App → It Runs!
        ↓
REAL DATA
CWA → API → JSON → Weather Center
        ↓
SECURITY TURN
WORKING ✓ → SECURE ?
        ↓
SECURITY THINKING
Asset → Threat → Vulnerability → CIA → Risk
        ↓
AI REVIEW + EVIDENCE
AI Suggestion → Evidence → Human Verification
```

## What L1 Does NOT Own

- Detailed Antigravity project management / Git / GitHub → **L2**
- Python / FastAPI / HTTP / API / JSON internals → **L3**
- Semgrep scan / remediation / re-scan workflow → **L4**
- Red Team exploitation → **L11–L12**
- Blue Team verified repair → **L13**

## Shared Lab

The Weather Security Center continues through the semester:

```text
L1 Build → L2 Manage → L3 Understand → L4 Secure
→ ML/DL → Authorized Red Team → Blue Team → Governance → Final Demo
```

## Safety Boundary

Only use localhost, student-owned code, teacher-provided code, owned isolated VM/container, or explicitly authorized classroom targets. Publicly accessible systems are not classroom attack targets.

## Core Statements

> **WORKING ≠ SECURE**

> **AI BUILDS. HUMAN VERIFIES.**

> **BUILD → THINK → VERIFY**
