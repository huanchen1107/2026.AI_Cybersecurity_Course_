# Lesson 1 — AI 資安工程師的工具箱

## Learning Goal
建立整門課共同工具與安全開發觀念，不把時間花在工具細節，而是讓學生知道每一個工具在 AI × Cybersecurity workflow 中扮演什麼角色。

## Suggested Outline
1. What is Vibe Coding?
2. Traditional Coding vs Vibe Coding
3. ChatGPT / Claude / Gemini / GitHub Copilot 能做什麼
4. AI Coding Agent 概念
5. Prompt 如何寫成需求
6. Requirements > 只叫 AI 寫 Code
7. Visual Studio Code
8. Git / GitHub
9. PHP / MySQL / MariaDB
10. XAMPP / Laragon
11. phpMyAdmin
12. Kali Linux
13. VMware
14. GitHub Dependency Graph / Dependency Awareness
15. 為什麼 AI 產生的程式可能不安全
16. Prompt → Plan → Code → Run → Test → Review → Fix
17. Lesson 2 Preview：AI Weather Security Center

## Core Message
> 不要只是叫 AI 寫程式；要學會叫 AI 做出「可以驗證、可以測試、而且安全」的程式。
