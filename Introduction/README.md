# Introduction — AI × Cybersecurity × Vibe Coding

## Course Vision

本課程以「做出來、攻擊它、修好它、最後治理它」為主軸，讓學生從 AI 輔助開發一路走到紅隊、藍隊與企業資安治理。

核心路徑：

```text
BUILD → ATTACK → DEFEND → GOVERN
```

五課主線：

1. Lesson 1 — AI 資安工程師工具箱
2. Lesson 2 — Vibe Coding 智慧天氣 IoT Dashboard
3. Lesson 3 — AI 紅隊：Kali Linux 滲透測試
4. Lesson 4 — AI 藍隊：OWASP Secure Coding 與修補
5. Lesson 5 — AI 資安治理：ISO 27001 與風險管理

## Course Philosophy

- AI generates. Human verifies. Security validates.
- Prompt 不只是問句，可以成為軟體需求與安全契約。
- 不可信資料跨越邊界時，可能被誤當指令或程式碼。
- AI Input、AI Output、External API、Database Data 都不應自動視為可信。
- Offensive security 實作限定於自有、授權、隔離 Lab / CTF 環境。

## Shared Project

全課共用同一個主專案：`AI Weather Security Center`。

```text
Weather API / Fake Sensor
        ↓
      PHP
        ↓
      MySQL

```

Lesson 2 建立系統，Lesson 3 攻擊自己的 Lab，Lesson 4 修補，Lesson 5 將其提升成風險治理案例。
