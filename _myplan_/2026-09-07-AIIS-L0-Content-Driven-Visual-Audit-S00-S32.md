Date: 2026-09-07

## Audit purpose

L0 must visually establish the semester journey before later lessons specialize. Visuals should explain WHY THIS COURSE, WHAT CHANGED, WHY SECURITY DISCIPLINE MATTERS, the persistent AI Weather Security Center, and the path into L1.

## Required visual story

```text
WHY THIS COURSE?
→ AI CHANGES HOW WE BUILD
→ SECURITY DISCIPLINE BECOMES MORE IMPORTANT
→ AI WEATHER SECURITY CENTER
→ SEMESTER JOURNEY
→ FIRST EXPERIENCE
→ HANDOFF TO L1
```

## Content-driven checks

- [x] Each slide has one primary teaching question or visual purpose.
- [x] Student-facing text remains lighter than the teaching script.
- [x] Visuals communicate concept before decorative styling.
- [x] Huange acts as Narrative Guide / Teaching Actor rather than a repeated sticker.
- [x] Character pose/action should respond to the actual object on each slide.
- [x] Generic hacker hood / generic AI brain should not become the default metaphor.
- [x] Persistent-project visuals should introduce and then reuse the same Weather Security Center object.
- [x] Semester journey should use one stable map/timeline rather than unrelated diagrams.
- [x] Final slides should visually hand the persistent project and student role into L1.

## Cross-slide callbacks

1. **AI capability / acceleration object**: introduced early as a change in how software is produced; later reused when discussing why verification discipline matters.
2. **Weather Security Center**: introduced as the persistent project and reused whenever the semester journey is shown.
3. **Semester Journey Map**: ORIENT → BUILD → MANAGE → UNDERSTAND → SECURE → LEARN → ATTACK → DEFEND → GOVERN → DEMO.
4. **Human verification / evidence language**: previewed in L0 and formally taught/reused in later lessons.
5. **L0 → L1 Handoff**: final visual should move from orientation map into a concrete BUILD mission, not a generic celebration slide.

## Huange role checks

Across S00–S32, Huange should rotate among roles such as Course Guide, Builder-in-training, Security Reviewer, Journey Navigator, Evidence Guide, and Handoff Guide. Adjacent slides should avoid identical pose unless deliberately used as a callback.

## Final production rule

> ONE SLIDE = ONE MAIN QUESTION + ONE MAIN VISUAL + ONE MEMORY LINE.

L0 is visually complete when a student can skim the slide sequence and infer the semester story without reading the full teacher script.
