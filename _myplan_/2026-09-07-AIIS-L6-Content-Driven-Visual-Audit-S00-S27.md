- [x] Feature importance is shown as model reliance, not causality.
- [x] Deep Tree visual communicates memorization/overfitting without teaching pruning algorithms.
- [x] Bootstrap sampling visibly shows replacement and repeated samples.
- [x] Random feature selection visually shows candidate subsets, not deleted features.
- [x] Voting visual clearly distinguishes individual Tree outputs from Forest output.
- [x] AI-generated interpretation cannot visually bypass Human Review / Evidence Gate.
