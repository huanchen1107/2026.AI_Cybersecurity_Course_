# AIIS_L1 — Content-Driven Visual Audit（S01–S30）

Date: 2026-09-07
Status: PASS WITH VISUAL ENHANCEMENTS
Purpose:逐頁確認 Visual 與「煥哥」不是裝飾，而是由當頁教學內容決定。

## Audit Standard
每頁檢查：Concept → Visual Metaphor → Huange Role → Expression → Action → Prop → Content Interaction → Placement。

## S01–S06
- S01 BUILD challenge — PASS. 煥哥=Host/Builder；應站在 Prompt→AI→Website→Security 流程起點，手勢把學生帶進工程旅程。
- S02 One Prompt→Website — PASS. 煥哥左手 Prompt、右手指完成網站，身體形成 input→output 方向。
- S03 Shared Lab — ENHANCE. 不只 product-demo；煥哥應把 Weather Center 放到 semester roadmap 起點，另一手指向 later Security/ML/Red/Blue/Risk，強化「共同 Lab」。
- S04 Skill Wall — PASS. 煥哥被 Python/API/JSON/Git/Security cards 包圍，再指向 BUILD FIRST→UNDERSTAND→VERIFY 出口。
- S05 Antigravity — ENHANCE. 煥哥必須位於 YOU 與 Agent 之間，一手交 Requirement、一手握 Responsibility badge，視覺化 YOU ARE STILL RESPONSIBLE。
- S06 Prompt — PASS. Launch Operator；手指 SEND/RUN，Prompt card 上 Requirement/Constraint/Security/Test 區塊清楚可見。

## S07–S12
- S07 Watch Agent Work — PASS. Reviewer clipboard 逐項勾 Plan/Create/Run/Test/Fix/Evidence，眼神跟著 workflow。
- S08 It Runs — PASS. 此頁允許一次成功 thumbs-up；人物指向真實網站成果。
- S09 Real Data — ENHANCE. 煥哥應站在 CWA 與 App 中間像 Boundary Inspector，手碰 external-data arrow，強化「外部資料進入我們系統」。
- S10 Follow the Data — PASS. 煥哥像 Data Flow Guide，手指跟著單一 highlighted packet 穿過 API→Parser→DataFrame→CSV/UI。
- S11 API+JSON — PASS. 左手 Request、右手 Response JSON，人物本身成為 request/response bridge。
- S12 Advanced Showcase — PASS. 一手展示、一手 open-palm stop；必須清楚表達 LOOK, DON'T BUILD，避免 scope creep。

## S13–S20
- S13 WORKING ✓ — PASS. 刻意極簡；煥哥只確認功能完成，不提前慶祝 Security。
- S14 SECURE ? — PASS. Skeptic；人物站在 WORKING 與 SECURE 斷橋旁，檢查缺口。
- S15 Assets — ENHANCE. Magnifier 必須實際對準 API Key/Data/Availability 等 asset cards，而不是泛指系統。
- S16 Asset Detective — PASS. 煥哥持 checklist 實際圈選 assets；學生任務視覺上從他手中接棒。
- S17 Threat — ENHANCE. 煥哥站在中心 Asset 旁，用環視/警戒姿勢面對 Attacker/Human Error/API Failure/Malware 等多來源，避免 Threat=Hacker 的錯誤暗示。
- S18 Vulnerability — PASS. 煥哥用 connector 把 Threat 接到 weakness，突出 `Why could it succeed?`。
- S19 Threat ≠ Vulnerability — ENHANCE. 煥哥左右各拿一張 card，中央放大 ≠；不能只是指表格。
- S20 Put It Together — PASS. Detective 把 Asset→Threat→Vulnerability 三張 evidence cards 串成 causal chain，最後指向 SO WHAT?。

## S21–S27
- S21 CIA — ENHANCE. 煥哥站在中心 APP，三個方向分別操作 eye/verified-data/service icons，讓 C/I/A 變成三個問題而非三個字母。
- S22 Confidentiality — PASS. API key 貼近身體、shielding gesture；public weather card 留在外側，呈現 authorization 差異。
- S23 Integrity — PASS. 左手 CWA truth、右手 website output，人物直接比較不一致資料。
- S24 Availability — ENHANCE. 煥哥不是只指 warning；應正在嘗試開啟 Weather Center，畫面回 `SERVICE UNAVAILABLE`，旁邊 Typhoon Day context，讓「需要時用不到」可視化。
- S25 Three Questions — PASS. 煥哥位於 APP 中央，三方向連 C/I/A。
- S26 Vulnerability→Risk — PASS. Security Analyst 在 Likelihood×Impact board 上放置當頁 Weather Center finding。
- S27 Risk Ranking — PASS. 煥哥親手把四張 finding cards 排入 matrix；API Key / eval() 優先於 cosmetic issue。

## S28–S30
- S28 Builder→Security Analyst — PASS. 最佳做法是同一煥哥左右雙狀態：Builder 拿 Prompt；Reviewer 拿 Evidence checklist，臉部一致。
- S29 Student Risk Detective — ENHANCE. 煥哥應把 magnifier / worksheet「遞向學生」，不是自己完成分析；人物角色從 Analyst 轉 Coach。
- S30 Closing — PASS. 煥哥一手托住完成的 Weather Center，一手指向 SCAN→FIND→UNDERSTAND→FIX→TEST→RE-SCAN→VERIFY road；不使用重複 thumbs-up。
